# V61.22 – Load / Calculate null-data fix

## Scope
This release changes only the New Pay Run **Load / Calculate** execution path.

- Waits for Payroll data to finish loading before calculation if necessary.
- Validates/parses the existing `paye.tax_codes` JSON rule before using `.find()` so a null/malformed value cannot cause the browser error `Cannot read properties of null (reading 'find')`.
- Keeps the existing payroll calculation formulas and rule values unchanged.
- No changes to timesheets, duplicate-pay protection, payslips, email, CSV, settings UI, or other modules.

## Deployment
Deploy the package to Netlify and hard-refresh the browser.

## SQL
No SQL migration is required.
