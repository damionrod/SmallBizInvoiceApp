# Finlo V61.48

Adds optional per-user operational access customisation on top of the V61.47 role defaults. Existing role defaults remain unchanged unless an Owner/Admin explicitly creates an override for a member.

## V61.56 Accountant Centre
Reports now includes an additive Accountant Centre for business-scoped Xero CSV preparation and a generic Accountant Pack. Xero exports require explicit per-business account and GST mappings and run pre-export validation. The Generic Accountant Pack exports only source data Finlo can support reliably. General Ledger, Trial Balance and accounting-grade Balance Sheet exports are deliberately not fabricated because this version of Finlo does not contain a complete double-entry ledger/opening-balance model.
