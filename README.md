# Invoice Manager v51

v51 adds the **My Expenses** module to the existing multi-business Invoice Manager while preserving the existing application.

The module includes an Expenses Dashboard, Bills & Expenses, mobile receipt/document capture, supplier management, business-specific categories, GST-inclusive/exclusive calculations, manual GST override, split expenses, partial payments, overdue status, separate reconciliation, batch payments, job allocation, reports/CSV export, duplicate warnings, private attachment storage and business-data export integration.

My Expenses is registered as a separately controllable module. Super Admin can enable or suspend it independently for each business through the existing **Modules** control.

Run `V51-MY-EXPENSES.sql` before deploying the site. See `V51-DEPLOYMENT-STEPS.md`.
