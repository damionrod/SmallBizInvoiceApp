# V61.30 Deployment Steps

1. Deploy the contents of this package to Netlify, replacing the current V61.29 site files.
2. No SQL or database migration is required.
3. Open Reports > Sales Report and confirm the new **Invoices Issued & Paid** grouped bar chart follows the existing Sales Report date range.
4. Confirm an invoice counts as **Fully paid** only when its existing invoice balance is zero.
5. Drag report cards using the small handle at the top-right of each widget. The order is saved locally per report tab.
6. Confirm Sales, Expense and Payroll report data/calculations remain unchanged.
