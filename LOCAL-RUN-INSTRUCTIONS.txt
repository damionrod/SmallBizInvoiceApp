FINLO LOCAL START

Windows:
1. Double-click START-FINLO-LOCAL.bat.
2. Finlo opens automatically at http://localhost:8765/index.html.
3. Allow microphone access when prompted for natural voice conversation.
4. Close the small server window when finished.

Python is optional. If Python is not installed, the launcher automatically uses
the included PowerShell server instead.

Do not open public/index.html directly with a file:// URL. Browser security blocks
the secure microphone/WebRTC and authenticated Supabase paths required by Finlo.
