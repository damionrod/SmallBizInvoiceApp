# V61.29 – Monthly Revenue, Expenses & Margin Report Chart

## Scope
Only the existing Reports > Sales Report section was changed.

## Added
- Grouped monthly bar chart for Revenue, Expenses and Margin.
- Uses the existing report From/To dates and quick ranges.
- Revenue follows the existing Finance/P&L invoice-date, ex-GST rule.
- Expenses use existing non-draft expense records by invoice date, ex GST.
- Margin = Revenue - Expenses.
- Currency values are shown above bars and in hover/tap tooltips.
- Responsive handling for longer date ranges and mobile screens.

## Database
No SQL or database changes are required.

## Deployment
Deploy the full contents of this package to Netlify in the same way as the previous version.
