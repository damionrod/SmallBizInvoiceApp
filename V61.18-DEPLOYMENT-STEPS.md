# V61.18 – Payroll Settings UI Cleanup

## Scope
Presentation-only update to Payroll > Settings.

### Changed
- Replaced raw JSON/statutory rule code display with human-readable payroll cards and values.
- PAYE and ESCT brackets are shown as readable income bands and percentages.
- Secondary rates and tax codes are shown as compact chips.
- IETC, Student Loan, KiwiSaver and ACC values are shown as labelled values.
- Reduced excess padding, margins and vertical spacing across Payroll Settings.
- Improved responsive layout for desktop, tablet and mobile.

### Not changed
- No payroll calculations or tax logic.
- No statutory rule values or database structure.
- No Pay Run, Timesheet, Payslip, Email, CSV, Employee or other module functionality.
- No SQL migration required.

## Deploy
Deploy this package to Netlify as usual. No Supabase SQL needs to be run for V61.18.
