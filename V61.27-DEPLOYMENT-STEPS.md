# V61.27 Deployment Steps

Scope: Payroll New Pay Run only.

1. Deploy this package to Netlify.
2. Finalise a pay run successfully.
3. Confirm Payroll switches to Pay Runs and the New Pay Run state is reset for a fresh run.
4. Return to New Pay Run, select the same already-finalised pay period and click Load / Calculate or Save Pay Run.
5. Confirm a clear "Pay run already finalised" duplication message is shown when all matching employees have already been finalised for that period.

No SQL migration is required.

No payroll calculations, statutory rules, duplicate-pay database protection, timesheets, payslips, email, CSV export, Payroll Settings, or other application modules were changed.
