# v60.2 — Country Payroll Tax Rules

This is a targeted Payroll/Super Admin update only.

1. In Supabase SQL Editor, run `V60.2-COUNTRY-PAYROLL-TAX-RULES.sql` from top to bottom.
2. Confirm the SQL completes successfully.
3. Deploy the complete v60.2 ZIP to Netlify.
4. Hard refresh the browser (`Ctrl + Shift + R`).
5. Open **Super Admin → Country Payroll Tax Rules**.
6. Confirm NZ rules are listed. Add future rule versions with an effective-from date rather than overwriting historical versions.
7. Payroll automatically uses the business Payroll country and the pay-run pay date. Finalised runs keep their rules snapshot.

No Edge Function changes are required.

Business Payroll Settings now show statutory country rules as read-only. Only Super Admin can change the central country rule table.
