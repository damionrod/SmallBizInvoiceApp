# V61.23 – PAYE Tax-Code Compatibility Fix

## Scope
This release changes only the Payroll `paye.tax_codes` compatibility reader used by New Pay Run → Load / Calculate.

- Keeps the existing array-based tax-code format unchanged.
- Also accepts tax-code JSON stored as an object/map and normalises it internally before the existing payroll calculation uses it.
- Supports object-wrapped arrays such as `codes`, `tax_codes`, `profiles`, or `items`.
- For a numeric tax-code map, treats the keys as secondary tax codes and preserves the existing M / ME primary-code behaviour already defined by the app's country-payroll rule migration.
- Does not change tax rates or payroll formulas.
- Does not modify Country Payroll Tax Rules data.
- Does not change any other module.

## Deployment
Deploy the package to Netlify as normal.

## SQL
No SQL migration is required.
