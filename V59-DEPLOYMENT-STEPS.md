# v59 – Financials P&L reconciliation and monthly layout

This is a targeted frontend update. No SQL migration and no Edge Function changes are required.

1. Deploy the v59 ZIP to Netlify.
2. Hard refresh the app (Ctrl+Shift+R).
3. Open Financials → Profit & Loss.
4. Select This Month and compare Sales with My Invoices for the same month.
5. Select Financial Year to Date / Last 6 Months / Last 12 Months to see month columns, including $0 months.
6. Confirm finalised Payroll wages/employer contributions and mapped Expense categories appear in costs.

Existing Invoice, Expense, Payroll, Job Costing, Customer and email workflows are unchanged.
