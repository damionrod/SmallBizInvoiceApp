# V61.15 – Restore Pay Run Email/CSV Actions

## Scope
This update restores the finalised pay-run action buttons in the responsive/mobile pay-run cards:
- Payslips
- Email Payslips
- Payday CSV

The existing desktop pay-run actions and duplicate-pay protection remain unchanged.

## Deployment
1. Deploy the contents of this package to Netlify.
2. No new SQL migration is required for V61.15.
3. If V61.14 duplicate-pay protection has not yet been installed, its SQL migration is still required separately.

## Verification
- Open Payroll > Pay Runs on desktop and mobile/narrow browser widths.
- Confirm a finalised pay run shows View, Delete, Payslips, Email Payslips, and Payday CSV.
- Confirm Email Payslips still sends payslips.
- Confirm Payday CSV still downloads the pay-run CSV.
- Confirm duplicate-pay protection still blocks already-paid timesheets as implemented in V61.14.
