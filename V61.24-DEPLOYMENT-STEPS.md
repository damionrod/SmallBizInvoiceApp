# V61.24 Deployment Steps

Deploy this package to Netlify.

Scope: New Pay Run tax-code rule parsing/compatibility only.

- Handles JSONB arrays/objects and older JSON-encoded string forms.
- If an older NZ `paye.tax_codes` row is malformed, reconstructs the same in-memory tax-code profiles from the active `paye.secondary_rates` map.
- Does not write or alter Country Payroll Tax Rules.
- Does not change tax rates or payroll formulas.
- No other modules changed.
- No SQL required.
