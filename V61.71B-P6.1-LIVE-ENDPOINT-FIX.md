# V61.71B-P6.1 — Live Voice endpoint fix

Diagnostic evidence showed the browser POSTing the Live Voice session request to the Netlify origin (`/.netlify/functions/v1/...`) and receiving HTTP 404.

Root cause: `finlo-helper.js` read infrastructure configuration from `window.SAAS.state.config`, but `saas.js` exposes the infrastructure configuration as `window.SAAS.config`.

Surgical fix only:
- Changed the two Live Voice configuration reads in `finlo-helper.js` from `window.SAAS?.state?.config` to `window.SAAS?.config`.
- Bumped only the `finlo-helper.js` cache query in `index.html` so browsers receive the corrected frontend file.

No Live architecture, model, voice, Product Knowledge, Basic Voice, accounting, GST/BAS, payroll, invoicing, expenses, bank reconciliation, onboarding, Import & Migration, tenant isolation, Edge Function, database, entitlement, or Netlify deployment change was made.
