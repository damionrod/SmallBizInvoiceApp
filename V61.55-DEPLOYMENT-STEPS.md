# Finlo V61.55 Deployment

## Already applied to the current Supabase project
- Migration `v61_55_ai_expense_scanning` has already been applied.
- Edge Function `scan-expense-document` version 1 has already been deployed with JWT verification enabled.

**Do not rerun the V61.55 SQL against the same Supabase project.**

## One required secret before AI scanning can work
Set the OpenAI API key as a Supabase Edge Function secret/environment variable named:

`OPENAI_API_KEY`

Do not put this key in `app-config.js`, browser JavaScript, localStorage, GitHub source, or the Finlo database.

Optional model override:

`OPENAI_EXPENSE_MODEL`

If omitted, the function uses `gpt-5.6-luna`.

## Frontend deployment
Deploy the V61.55 frontend to the **Dev** Netlify deployment first. The only existing frontend files changed are:
- `index.html`
- `expenses.js`
- `styles.css`
- `saas.js` (cache-bust version for expenses.js only)

Then test on desktop and a phone before promoting to production.
