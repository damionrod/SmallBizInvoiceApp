# V61.71B-P6 GitHub Upload Set

This folder is a GitHub web-upload-friendly copy of the accepted V61.71B-P6 application.

- Application/runtime source files are unchanged from the complete P6 package.
- The current Supabase function source tree is included unchanged.
- The P6 migration and P6 implementation/regression reports are included.
- Historical release reports and superseded root SQL migration files are intentionally omitted from this upload set so the browser upload stays below GitHub's 100-file web-upload limit.
- This upload set is NOT a replacement for the complete archival P6 ZIP. Keep the complete P6 ZIP as the authoritative archive.
- Upload these files into the same repository paths. Do not delete existing historical files from GitHub merely because they are absent from this upload set.
