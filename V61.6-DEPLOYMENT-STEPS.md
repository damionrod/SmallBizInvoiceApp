# V61.6 Deployment Steps

This release fixes New Pay Run save/finalisation reliability and small UI text consistency issues only.

1. Deploy the updated application files from this package.
2. No new SQL migration is required for V61.6.
3. Make sure the earlier V61 SQL migration has already been run if you are using timesheet reimbursements/finalised pay-run deletion.
4. Hard refresh the browser after deployment.
5. Test: create/load a pay run, select employees, finalise it, confirm the app opens Payroll → Pay Runs, confirm the run shows as Finalised, and open Payslips.

If a Supabase operation fails during finalisation, the app now identifies the failing save step instead of displaying a success message.
