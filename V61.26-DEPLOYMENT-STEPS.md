# V61.26 – Payroll rule helper collision fix

## Scope
This release fixes only the New Pay Run Load / Calculate failure caused by a duplicate JavaScript helper name.

The Payroll calculation helper `ruleJson(type, key, date, fallback)` was being overwritten by the later Payroll Settings display helper also named `ruleJson(r)`. This caused PAYE annual bracket and other JSON payroll-rule lookups to receive the wrong value shape.

V61.26 renames only the display helper to `ruleDisplayJson(r)` and updates its single display usage.

## Deployment
1. Deploy the contents of this package to Netlify.
2. Hard refresh the browser.
3. Open Payroll > New Pay Run and test Load / Calculate.

## Database
No SQL migration is required.

## Unchanged
No payroll formulas, statutory rates, employee/timesheet logic, pay-run save/finalise logic, payslips, email, CSV exports, Settings behaviour, or other modules were changed.
