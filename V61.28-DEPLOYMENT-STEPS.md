# V61.28 – Quote List Delete & Email Send

This release changes only **Job Costing → Quotes**.

## Changes
- Added a **Delete** button to each quotation row, with a confirmation prompt before deletion.
- Added an editable **email address** field to each quotation row.
- The email field is pre-populated from the quote/customer billing email when available.
- Added a **Send** button that sends the quotation PDF to the email address currently typed in that row.
- The typed recipient does not overwrite the customer's saved contact email; it is used for that send and is recorded as the quote's last sent-to address.
- Existing quote status handling remains unchanged: a draft becomes Sent after a successful email; other statuses are preserved.

## Database
No SQL or database migration is required.

## Scope
No changes were made to Invoicing, Expenses, Payroll, Financials, Customers, Reports, Job Costing calculations, quote calculations, or other modules.
