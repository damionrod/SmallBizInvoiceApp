# Frindly v61.99F — Phase 5 Mobile Workflows

Complete GitHub-ready replacement package.

Phase 5 is deliberately scoped to mobile workflow presentation for Schedule, Create Invoice, Expense/Purchase Review and Payroll Run. It does not change accounting calculations, database schema, Supabase logic, permissions, entitlements, subscription logic, GST logic or desktop workflow logic.

Mobile changes:
- Schedule: phone-first day workspace, calendar before unscheduled queue, simpler toolbar, contained week scroller, single-column editor.
- Create Invoice: single-column details, mobile line-item cards, clearer totals/options, reachable sticky actions.
- Expense/Purchase Review: single-column review/allocation flow and reachable actions.
- Payroll Run: full-height phone workspace, single-column review, mobile summary and fixed final actions.
- Asset cache version bumped to v61.99F-phase5.
