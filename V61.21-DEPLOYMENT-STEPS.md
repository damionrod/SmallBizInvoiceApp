# V61.21 Deployment Steps

1. Deploy this package to Netlify.
2. No SQL migration is required.
3. Open Payroll > New Pay Run.
4. Confirm the page loads.
5. Choose the pay period/frequency and click **Load / Calculate**.
6. Confirm eligible employees and payroll calculations load as before.

Scope: New Pay Run initialization and Load / Calculate event binding only. No payroll calculation formulas, tax rules, duplicate-pay protection, settings, payslips, email, CSV, or other modules were changed.
