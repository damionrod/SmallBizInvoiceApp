Staging-test-harness-only correction. The reviewed migration, application runtime and any Edge Function content are unchanged.

## Correction
Immediately after creating `v6179a_results`, the harness now grants:
`GRANT SELECT, INSERT ON v6179a_results TO authenticated;`

This is the minimum table access required because `pg_temp.assert_true()` is SECURITY INVOKER and inserts test results after the harness has switched to `SET LOCAL ROLE authenticated`. SELECT is also required for the final results read if the session remains or returns to that role in future harness maintenance.

- `pg_temp.as_user()` temporary-schema function — called before/while changing local role and only sets transaction-local request claims/role.

No UPDATE, DELETE, TRUNCATE, REFERENCES, TRIGGER or ALL privilege is granted on the results table.
