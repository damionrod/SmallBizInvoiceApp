# V61.79 Phase B — Schedule + Dashboard test report

## Baseline
V61.79E is the authoritative baseline. The two reviewed Phase A migrations are unchanged.

## Checkpoint 1 — Native Schedule
Implemented in `public/schedule.js` with loader/navigation integration and responsive styling. Schedule is entitlement-gated and owner/admin-only. Direct navigation fails closed to Dashboard when Schedule is unavailable. Queries are explicitly active-business scoped and stale results are discarded after a business change.

Implemented: Day/Week views; week working-hour grid; Today/previous/next navigation; current-hour indicator; employee/status/customer filters; create/edit/delete/cancel/status changes; searchable existing-record selects; multiple employee assignments; drag to a dated hourly slot; move back to Unscheduled; immediate Supabase persistence; optimistic drag rollback on error; mobile day-first layout; recurrence-rule capture.

### Recurrence generation limitation
The reviewed Phase A schema stores recurrence rules and has a uniqueness guard for generated occurrences, but it does not provide a reviewed server-side occurrence-generation RPC/job. V61.79 therefore saves recurrence rules but intentionally does not bulk-generate occurrences in the browser. A server-side generator is a later dependency so concurrent clients, timezones and idempotency can be handled safely.

## Checkpoint 2 — Dashboard
Implemented in `public/dashboard.js` and made the authenticated landing view. It uses `v6179_dashboard_summary` and `v6179_today_schedule`, plus business-scoped authoritative operational records already used by the existing modules. Money received uses `customer_payments`; cash-out movement uses `expense_payments`; outstanding uses invoice balances; expenses use recorded expense rows excluding GST. Imported bank transactions are never presented as cash balance. Unsupported profit/forecast values show unavailable states rather than `$0`.

Dashboard includes contextual greeting/actions, Business Pulse, cash movement, Today Schedule or an entitlement-safe alternative, concise Needs Attention, quick insight, skeleton loading, empty states and mobile prioritisation.
