# V61.79 Phase B — Frontend Week-Hours Correction

## Scope

Baseline: `finlo-v61.79-PHASE-B-CONSOLIDATED-CORRECTION(2).zip` only.

This is a frontend-only correction. No database migration, RLS policy, Dashboard logic, accounting, payroll, GST, Stripe, deployment configuration, or production data was changed.

## Correction

- Week view keeps its normal 07:00–19:59 grid when all scheduled jobs fall within normal hours, or when the week has no scheduled jobs.
- The Week grid now expands to the earliest and latest local start hour represented by scheduled jobs in the visible week.
- A 06:15 job adds the 06:00 row.
- A 21:07 job adds the 20:00 and 21:00 rows and renders in the 21:00 row.
- Expansion uses each schedule's selected IANA timezone through the existing `utcToLocal` conversion.
- Day view, mobile default, drag-and-drop, loading, atomic save, and all other Schedule behaviour are unchanged.
