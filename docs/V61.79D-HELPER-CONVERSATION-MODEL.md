# Finlo Helper conversation model

The production `finlo-helper` Edge Function is version 5 (`v61.79D-CONVERSATION-SOL`).
All typed and browser conversation requests use `gpt-5.6-sol` explicitly. The model is
not taken from the editable admin settings, so a stale settings value cannot silently
downgrade conversation quality. The response includes a diagnostic backend version and
selected product topics for support verification.
