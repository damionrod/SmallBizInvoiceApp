# v62.36 Market final-pay preparation

This Market-only checkpoint replaces the direct employee termination update with a guarded preparation workflow.

- Employment termination and review creation are one atomic database command.
- The command checks Payroll write permission, tenant ownership, the employee record revision, dates, and a request UUID.
- Repeated requests are idempotent and only one open review can exist per employee.
- Frindly marks final pay as needing review but does not guess or automatically finalise a statutory amount.
- The employee list displays the final-pay review state on desktop and mobile.
- Direct selection of `Terminated` in the employee form routes the user into this workflow.
- Tenant state clearing now also clears PAYG, annual-holiday and final-pay arrays.

The next payroll batch can build the evidence-entry and P6 calculation screen on this safe boundary.
