## Implemented cleanup
- Added `finlo-core.js` as a deliberately small shared primitive layer.
- Centralised ordered dynamic script loading and removed the deeply nested module-loader callback chain from `saas.js` while preserving exact module order.
- Adopted shared DOM/numeric/HTML-escape primitives in a small set of modules where semantics were identical (`expenses.js`, `accountant-centre.js`, `referrals.js`).
- Split the first brace-balanced 385 lines of the existing CSS cascade into `styles-core.css`; remaining rules stay in `styles.css`. The two files are loaded consecutively, preserving original CSS order. `frontend-quality.css` remains last.
- Added architecture audit, architecture manifest and V61.72B backlog.
